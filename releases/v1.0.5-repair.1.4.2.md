# AlwaysStrongFork · Repair 1.4.2

**Author: [@SUKISU_ULTR4](https://t.me/SUKISU_ULTR4)** · [Support](https://t.me/alwaysstrongfork)

versionCode: **114**. Stability fixes for startup, repeated TEE launches, native Isolation IPC and target-list transactions. No physical-device boot test has been performed.

## Changes

- **Removed font memory remapping** from Isolation. The previous pre-specialization memory copy/replacement could crash an app on stale or truncated file mappings. Old enable settings are ignored and cannot reactivate it; font paths may remain visible.
- Isolation requests stay inactive until Android completes boot plus a **120-second settle period**. A readiness token must match the current boot; disable/remove markers, malformed configuration or timeout result in no action. Child zygotes and SDK sandbox UIDs are excluded.
- A complete native IPC request/response shares one **150 ms monotonic deadline after connection**. FIFOs, symlinks, directories and oversized config files are rejected. The Zygisk provider's own connection call is outside this deadline.
- The TEE restart budget survives supervisor crashes in the same boot. Time windows use monotonic uptime; keybox checks before every launch are bounded. Corrupted counters cannot overflow to bypass the boot guard; pending removal prevents startup.
- The process-group deadline helper no longer blocks in `wait()` after killing an expired task. Kernel-uninterruptible I/O cannot be forcibly repaired by this module.
- Target rebuilds use one writer lock, a 45-second deadline and unique temporary files before atomic publication. The watcher no longer truncates the live target list while an attestation engine may be reading it. Imported-file cleanup accepts only safe XML basenames.
- Release CI rebuilds **both** Android ARM helpers from the checked-out source.

## Installation

Install one main ZIP over the existing module, keep `/data/adb/tricky_store`, and reboot:

- `AlwaysStrong-v1.0.5-repair.1.4.2.zip` — default.
- `AlwaysStrong-v1.0.5-repair.1.4.2-inject.zip` — inject-s.
- `AlwaysStrong-v1.0.5-repair.1.4.2-nopif.zip` — Lite, without bundled PIF.
- `AlwaysStrong-Isolation-v1.0.5-repair.1.4.2.zip` — separate optional experimental companion; update this too if 1.4.1 Isolation was installed. Updating the main ZIP alone does not replace the separate companion.

Android 10+, ARM64/ARMv7. Default/Inject require Zygisk; the companion requires a compatible Zygisk API v5 provider. Restart selected apps after the companion activates.

## Verification and limits

**64 Python + 6 Rust tests**, Android ARM64/ARMv7 cross-compilation, exported-entry checks, four ZIP structure checks and `SHA256SUMS.txt`. New tests cover slow peers, invalid config files, boot readiness, interrupted supervisors, damaged counters, pending removal and target-list publication.

See the [boot safety review](https://github.com/zaigraevstepan7-afk/Alwaysstrongfork/blob/main/docs/BOOT_SAFETY_REVIEW.md) for scope, failure modes and recovery. A source audit cannot guarantee the absence of bootloops on every ROM. Pinned third-party TEE/PIF payloads are unchanged; Soter hardware repair and a clean detector verdict remain unverified.
