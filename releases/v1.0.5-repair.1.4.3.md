# AlwaysStrongFork v1.0.5-repair.1.4.3

This release fixes the Action shell regression observed on Android 14: the log
contained repeated `row: inaccessible or not found` errors while the WebUI
reported completion.

- Quote the literal parenthesis in version suffix removal for Android mksh.
  Previously mksh could consume the `row()` function definition into that pattern.
- Make the BusyBox hop marker process-specific. A new shell launched by the
  native Action lock no longer inherits a stale "already using ash" flag.
- Add the Action button and persistent live log dialog to the main WebUI.
  Reopening the interface reconnects to the saved run; duplicate taps preserve it.
- Share a native lock across manager, WebUI, boot and reset Action entries.
  Bound WebUI work to eight minutes and retain its stdout, stderr and exit status.
- Return failure for required-step errors and a separate warning status for
  partial completion. Check required shell functions before performing work.
- Show the installed version in the WebUI. Include Action logs in diagnostics.
- Add mksh/other-shell execution fixtures and worker regression tests. CI installs
  mksh and BusyBox, rebuilds ARM helpers, and verifies the installable ZIPs.

Choose one main ZIP: the plain file uses PlayIntegrityFork, `-inject` uses
PlayIntegrityFix inject-s, and `-nopif` is Lite. The Isolation ZIP is a separate,
optional experimental companion. Update through the root manager and reboot.

Host/CI checks are not a physical Android boot test. Completion is a script
result, not a Play Integrity verdict; run an independent checker afterward.
The bundled upstream TEESimulator-RS payload remains v6.0.1-307.
