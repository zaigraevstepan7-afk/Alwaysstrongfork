# AlwaysStrongFork · Repair 1.3.1

**Fork author: [@SUKISU_ULTR4](https://t.me/SUKISU_ULTR4)**

Support: [@alwaysstrongfork](https://t.me/alwaysstrongfork)

The first release from this repository, based on Repair 1.3. Engines and recovery logic are preserved; project presentation, variant metadata, and the release process have been updated.

## Changes

- English project documentation covering features, requirements, installation, checker result imports, recovery, and diagnostics.
- Consistent AlwaysStrongFork naming, with the fork author listed first and upstream attribution preserved.
- Update URLs for all variants point to this repository.
- The build verifies the default, Inject, and Lite ZIPs, rebuilds Android asfetch from source, and runs 40 Python + 6 Rust tests.
- Releases are published only after a successful main branch build. `SHA256SUMS.txt` contains installation ZIP checksums.
- versionCode increased to 111.

## Choose a ZIP

| File | Contents |
| --- | --- |
| `AlwaysStrong-v1.0.5-repair.1.3.1.zip` | Default: PlayIntegrityFork + TEESimulator-RS. |
| `AlwaysStrong-v1.0.5-repair.1.3.1-inject.zip` | Alternative: PlayIntegrityFix inject-s + TEESimulator-RS. |
| `AlwaysStrong-v1.0.5-repair.1.3.1-nopif.zip` | Lite: TEESimulator-RS without bundled PIF. |

Start with the default ZIP. Install one variant at a time through Magisk / KernelSU / APatch, then reboot. Android 10+ and ARM64 or ARMv7 are required. The default and Inject variants require working Zygisk. This Repair build does not support x86/x86_64.

When upgrading an earlier Repair build, do not delete `/data/adb/tricky_store`. If the installer detects another active PIF/TEE module, resolve the conflict manually first.

The default ZIP does not include a keybox. Import one or use the module's download function. Keybox file health and actual Play Integrity results are separate checks: run an external checker and import its fresh JSON into WebUI. BASIC/DEVICE/STRONG results and compatibility with a particular app are not guaranteed. Release validation did not include installation on a physical device.
