# AlwaysStrongFork · Repair 1.3.1

**Автор форка: [@SUKISU_ULTR4](https://t.me/SUKISU_ULTR4)**
Поддержка: [@alwaysstrongfork](https://t.me/alwaysstrongfork)

Первый релиз этого репозитория на основе Repair 1.3. Движки и логика восстановления сохранены; обновлены оформление проекта, метаданные вариантов и процесс выпуска.

## Что изменилось

- README на русском: возможности, требования, установка, импорт результата чекера, восстановление и диагностика.
- Единое имя AlwaysStrongFork; автор форка указан первым, исходное авторство сохранено.
- Обновления всех вариантов направлены в этот репозиторий.
- Сборка проверяет основной, Inject и Lite ZIP, пересобирает Android asfetch из исходников и выполняет 40 Python + 6 Rust тестов.
- Релиз публикуется только после успешной сборки ветки main. SHA256SUMS.txt содержит контрольные суммы установочных ZIP.
- versionCode повышен до 111.

## Какой ZIP выбрать

| Файл | Состав |
| --- | --- |
| `AlwaysStrong-v1.0.5-repair.1.3.1.zip` | Основной: PlayIntegrityFork + TEESimulator-RS. |
| `AlwaysStrong-v1.0.5-repair.1.3.1-inject.zip` | Альтернативный: PlayIntegrityFix inject-s + TEESimulator-RS. |
| `AlwaysStrong-v1.0.5-repair.1.3.1-nopif.zip` | Lite: TEESimulator-RS без встроенного PIF. |

Начните с основного ZIP. Устанавливается один вариант за раз через Magisk / KernelSU / APatch, затем нужна перезагрузка. Требуются Android 10+ и ARM64 или ARMv7. Для основного и Inject вариантов нужен работающий Zygisk. x86/x86_64 этой Repair-сборкой не поддерживаются.

При обновлении предыдущей Repair-сборки удалять `/data/adb/tricky_store` не нужно. Если установщик обнаружил другой активный PIF/TEE-модуль, сначала разрешите конфликт вручную.

Keybox не включён в основной ZIP. Его можно импортировать или загрузить средствами модуля. Состояние keybox и настоящий результат Play Integrity — разные проверки: выполните проверку отдельным чекером и импортируйте свежий JSON в WebUI. Прохождение BASIC/DEVICE/STRONG и совместимость с конкретным приложением не гарантируются; установка на физическом устройстве в рамках выпуска не выполнялась.

Исходные компоненты: AlwaysStrong — Evokerr, TEESimulator / TEESimulator-RS — JingMatrix / Enginex0, PlayIntegrityFork — osm0sis, PlayIntegrityFix inject-s — KOWX712. Лицензия проекта: GPL-3.0.
